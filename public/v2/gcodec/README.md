Benchy toolpath illustration

Rendered from the owner's `Downloads/benchy.gcode` (OrcaSlicer, 240 layers).
Only labelled object moves are included, without printer startup/purge paths.
Projection: 35-degree azimuth, 30-degree elevation. Green extrusion paths
are shaded by depth; blue travel paths and red retractions remain visible.

Regenerate the SVG using `scripts/render-gcodec-benchy.py`, then rasterize
at 2400px and encode as WebP quality 95 with sharp. Background stays transparent.
This is a static presentation of actual toolpaths, not a live viewer.
